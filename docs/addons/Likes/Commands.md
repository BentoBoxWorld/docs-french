**Commandes disponibles (à partir de 1.7.0)**

| Commande                              | Permission                      | Description                                                                            |
|--------------------------------------|---------------------------------|----------------------------------------------------------------------------------------|
| /[gamemode_user] likes               | [gamemode].likes                | Permet d'ouvrir l'interface graphique pour ajouter des j'aime aux îles des autres joueurs ou vérifier vos j'aime d'île |
| /[gamemode_user] likes view          | [gamemode].likes.view           | Permet d'ouvrir l'interface graphique avec l'affichage des j'aime de votre île                                         |
| /[gamemode_user] likes view <player> | [gamemode].likes.view.others    | Permet d'ouvrir l'interface graphique avec l'affichage des j'aime de l'île du joueur cible                                |
| /[gamemode_user] likes top <type>    | [gamemode].likes.top            | Permet d'ouvrir l'interface graphique avec le top d'île demandé                                           |
| /[gamemode_admin] likes              | [gamemode].likes.admin          | Permet d'ouvrir l'interface graphique Admin                                                               |
| /[gamemode_admin] likes settings     | [gamemode].likes.admin.settings | Permet d'ouvrir l'interface graphique Addon Settings                                                      |
| /[gamemode_admin] likes view <player>| [gamemode].likes.admin          | Permet d'ouvrir l'interface graphique avec l'affichage des j'aime de l'île du joueur cible                                |
