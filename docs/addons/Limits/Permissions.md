## **Limits** (addon.yml)

Remplacez [gamemode] par le nom du mode de jeu, par exemple bskyblock, acidisland, etc.

| **Permission**                     | **Activer pour** | **Description**                        |
|-------------------------------------|----------------|----------------------------------------|
| [gamemode].mod.bypass               | op             | Le joueur peut contourner les limites               |
| [gamemode].limits.admin.limits      | op             | Le joueur peut utiliser la commande des limites admin    |
| [gamemode].limits.player.limits     | true           | Le joueur peut utiliser la commande des limites          |
