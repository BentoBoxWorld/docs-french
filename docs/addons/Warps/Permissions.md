## Permissions Warps

Les permissions d'utilisation sont (mettez le nom du mode de jeu, par exemple acidisland à l'avant):

```
   [gamemode].island.warp:
    description: Le joueur peut utiliser les commandes warp ou warps
    default: true
  [gamemode].island.addwarp:
    description: Le joueur peut créer un panneau de téléportation de bienvenue
    default: true

```
