## **Permissions Greenhouses**

| **Permission**                     | **Description**                                                                                                                                     | **Par défaut** |
|-------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------|-------------|
| [gamemode].greenhouses.player       | Donne accès aux commandes du joueur - remplacez [gamemode] par votre mode de jeu, par exemple bskyblock, acidisaland, aoneblock, etc.                                  | true        |
| [gamemode].greenhouses.admin        | Donne accès aux commandes admin                                                                                                                      | op          |
| [gamemode].greenhouses.admin.list   | Permet de lister les serres (depuis la 1.10.0)                                                                                                      | op          |
| [gamemode].greenhouses.admin.info   | Permet de consulter le détail d'une serre (depuis la 1.10.0)                                                                                        | op          |
| [gamemode].greenhouses.admin.delete | Permet de supprimer l'enregistrement d'une serre (depuis la 1.10.0)                                                                                 | op          |
| [gamemode].greenhouses.admin.tp     | Permet de se téléporter à une serre (depuis la 1.10.0)                                                                                              | op          |
| [gamemode].greenhouses.admin.verify | Permet de revérifier les serres par rapport à leur recette (depuis la 1.10.0)                                                                       | op          |
| [gamemode].greenhouses.admin.reload | Permet de recharger biomes.yml et la base de données des serres (depuis la 1.10.0)                                                                  | op          |
| greenhouses.biome.nether            | Donne accès aux biomes du Nether. Les permissions par biome sont définies dans `biomes.yml` - voir la [page Greenhouses](index.md#permissions).       | true        |
