# Farmers Dance

**Farmers Dance** est un simple addon qui permet aux joueurs de danser près de n'importe quelle plante pour qu'elle pousse.

Créé et maintenu par [BONNe](https://github.com/BONNe).

{{ addon_description("FarmersDance", beta=True) }}

## Installation

1. Placez le fichier jar de l'addon dans le dossier des addons du plugin BentoBox
2. Redémarrez le serveur
3. L'addon générera un fichier config que vous pouvez modifier.

## Informations

L'idée principale du addon est de permettre une croissance plus rapide de n'importe quelle plante sur votre île.
La principale différence avec TwerkingForTrees est que cet addon devrait fonctionner sur n'importe quelle plante cultivable, y compris les cactus, les citrouilles et les champignons.

### config.yml

Une fois l'addon correctement installé, il créera un fichier config.yml. Chaque option dans ce fichier est accompagnée de commentaires. Veuillez vérifier le fichier pour plus d'informations.
Vous pouvez trouver le dernier fichier config : [config.yml](https://github.com/BentoBoxWorld/FarmersDance/blob/develop/src/main/resources/config.yml)

## Permissions

!!! tip
    `[gamemode]` est un préfixe qui diffère selon le mode de jeu que vous exécutez.
    Le préfixe est le nom du mode de jeu en minuscules, c'est-à-dire que si vous utilisez BSkyBlock, le préfixe est `bskyblock`.
    De même, si vous utilisez AcidIsland, le préfixe est `acidisland`.

=== "Permissions du joueur"
    - `[gamemode].farmersdance` - Permet au joueur d'utiliser la danse pour cultiver les plantes.


??? question "Quelque chose manque-t-il?"
    Vous pouvez trouver la liste complète des permissions dans le fichier [addon.yml](https://github.com/BentoBoxWorld/FarmersDance/blob/develop/src/main/resources/addon.yml) de cet addon.
    Si quelque chose manque vraiment de la liste ci-dessous, veuillez nous le faire savoir!
