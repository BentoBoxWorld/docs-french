# Commandes AOneBlock

AOneBlock a beaucoup des mêmes commandes que BSkyBlock. Voici les commandes uniques :

**NOTE** cette liste n'est pas encore complète.

## Commandes Admin

* `/obadmin setchest <phase> <rarity>` définir un coffre regardé pour être dans une phase avec une rareté donnée
* `/obadmin setcount <name> <count>`: définir le nombre de blocs de l'île du joueur
* `/obadmin sanity <phase>`: afficher une vérification de santé des probabilités de phase dans la console

Les valeurs de rareté du coffre peuvent être COMMON, UNCOMMON, RARE et EPIC.

## Commandes utilisateur

* `/ob count` - afficher le nombre et la phase sur laquelle l'île est en ce moment
* `/ob setcount <number>` - changer le nombre de blocs minés
* `/ob phases` - afficher l'interface utilisateur des phases
* `/ob bossbar` - basculer l'affichage de la barre de boss affichant la progression de la phase (depuis 1.21.2, nécessite `bossbar: true` dans config)
* `/ob actionbar` - basculer l'affichage de la barre d'action affichant la progression de la phase (depuis 1.21.2, nécessite `actionbar: true` dans config)
