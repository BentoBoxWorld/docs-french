# Permissions AOneBlock

| Permission                       | Activer pour | Description                                        |
|-----------------------------------|------------|----------------------------------------------------|
| aoneblock.admin                   | op         | Autoriser l'utilisation de la commande '/obadmin' — commande admin    |
| aoneblock.admin.blueprint         | op         | Autoriser l'utilisation de la commande '/obadmin blueprint' — gérer les blueprints |
| aoneblock.admin.clearresetall     | op         | Autoriser la suppression de la limite de réinitialisation d'île pour tous les joueurs |
| aoneblock.admin.delete            | op         | Permettre à un joueur de supprimer complètement un joueur (y compris l'île) |
| aoneblock.admin.getrank           | op         | Obtenir le rang d'un joueur |
| aoneblock.admin.noban             | op         | Le joueur ne peut pas être banni d'une île |
| aoneblock.admin.noexpel           | op         | Le joueur ne peut pas être expulsé d'une île |
| aoneblock.admin.purge             | op         | Autoriser l'utilisation de la commande '/obadmin purge' — purger les îles abandonnées depuis plus de jours spécifiés |
| aoneblock.admin.range             | op         | Autoriser l'utilisation de la commande '/obadmin range' — gérer la portée de l'île |
| aoneblock.admin.register          | op         | Permettre à un joueur d'enregistrer l'île la plus proche à un autre joueur |
| aoneblock.admin.reload            | op         | Recharger le config.yml |
| aoneblock.admin.setchest          | op         | Placer le coffre regardé dans une phase avec une rareté donnée |
| aoneblock.admin.setlanguage       | op         | Réinitialiser les langues de tous les joueurs et définir la langue par défaut |
| aoneblock.admin.setrank           | op         | Définir le rang d'un joueur |
| aoneblock.admin.setrange          | op         | Autoriser la définition de la portée de protection de l'île |
| aoneblock.admin.setspawn          | op         | Autoriser l'utilisation des outils de spawn |
| aoneblock.admin.settingsreset     | op         | Réinitialiser toutes les îles aux paramètres de protection par défaut |
| aoneblock.admin.tp                | op         | Autoriser la téléportation sur une île |
| aoneblock.island.actionbar        | true       | Autoriser l'utilisation de la commande '/ob actionbar' — basculer l'affichage de la progression de la barre d'action |
| aoneblock.island.bossbar          | true       | Autoriser l'utilisation de la commande '/ob bossbar' — basculer l'affichage de la progression de la barre de boss |
| aoneblock.count                   | true       | Autoriser l'utilisation de la commande aoneblock count |
| aoneblock.island                  | true       | Autoriser l'utilisation de la commande '/ob' — la commande d'île principale |
| aoneblock.phases                  | false      | Autoriser l'utilisation de la commande '/ob phases' — afficher une liste de toutes les phases |
| aoneblock.island.ban              | true       | Autoriser l'utilisation de la commande '/ob ban' ou '/ob unban' — gérer les joueurs bannis |
| aoneblock.island.create           | true       | Autoriser l'utilisation de la commande '/ob create' — créer une île, en utilisant un blueprint optionnel |
| aoneblock.island.deletehome       | op         | Autoriser l'utilisation de la commande '/ob deletehome' — supprimer un emplacement d'accueil |
| aoneblock.island.expel            | true       | Autoriser l'utilisation de la commande '/ob expel' — expulser les visiteurs |
| aoneblock.island.home             | true       | Autoriser l'utilisation de la commande '/ob go' — se téléporter sur votre île |
| aoneblock.island.homes            | op         | Autoriser l'utilisation de la commande '/ob homes' — lister vos accueils |
| aoneblock.island.info             | true       | Autoriser l'utilisation de la commande '/ob info' — afficher les informations sur l'île |
| aoneblock.island.language         | true       | Autoriser l'utilisation de la commande '/ob language' — sélectionner une langue |
| aoneblock.island.lock             | true       | Autoriser le verrouillage de l'île dans les paramètres |
| aoneblock.island.name             | true       | Autoriser l'utilisation des commandes '/ob setname' ou '/ob resetname' — définir le nom de votre île |
| aoneblock.island.near             | true       | Autoriser l'utilisation de la commande '/ob near' — afficher le nom des îles proches |
| aoneblock.island.renamehome       | op         | Autoriser l'utilisation de la commande '/ob renamehome' — renommer un emplacement d'accueil |
| aoneblock.island.reset            | true       | Autoriser l'utilisation de la commande '/ob reset' — redémarrer votre île |
| aoneblock.island.setcount         | op         | Autoriser l'utilisation de la commande '/ob setCount' — définir le nombre de blocs à la valeur complétée |
| aoneblock.island.sethome          | true       | Autoriser l'utilisation de la commande '/ob sethome' — définir votre point de téléportation d'accueil |
| aoneblock.island.settings         | true       | Autoriser l'utilisation de la commande '/ob settings' — afficher les paramètres de l'île |
| aoneblock.island.spawn            | true       | Autoriser l'utilisation de la commande '/ob spawn' — se téléporter au spawn de l'île si défini |

| aoneblock.island.team.kick        | true       | Autoriser l'utilisation de la commande '/ob team kick' — supprimer un membre de l'équipe |
| aoneblock.island.team.leave       | true       | Autoriser l'utilisation de la commande '/ob team leave' — quitter l'équipe de l'île |
| aoneblock.island.team.promote     | true       | Autoriser l'utilisation de la commande '/ob team promote' — promouvoir un membre de l'équipe |
| aoneblock.island.team.reject      | true       | Autoriser l'utilisation de la commande '/ob team reject' — rejeter une invitation |
| aoneblock.island.team.setowner    | true       | Autoriser l'utilisation de la commande '/ob team setowner' — transférer la propriété de l'île |
| aoneblock.island.team.trust       | true       | Autoriser l'utilisation de la commande '/ob team trust' — approuver un joueur sur votre île |
| aoneblock.mod.bypassban           | op         | Ignore le bannissement de l'île |

| aoneblock.mod.bypassdelays        | op         | Autoriser le modérateur à ignorer les délais |
| aoneblock.mod.bypassprotect       | op         | Autoriser le modérateur à ignorer la protection de l'île |
| aoneblock.mod.clearreset          | false      | Autoriser la suppression de la limite de réinitialisation de l'île |
| aoneblock.mod.info                | op         | Permettre à un modérateur de voir les informations sur un joueur |
| aoneblock.mod.lock                | op         | Autoriser ou interdire le verrouillage d'une île |

| aoneblock.respawn-block           | true       | Autoriser l'utilisation de la commande '/ob respawnBlock' — respawn du bloc magique |
| aoneblock.settings.*              | true       | Autoriser l'utilisation des paramètres sur l'île |
