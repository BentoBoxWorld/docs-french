# Autorisations AcidIsland { #acidisland-permissions }

Les autorisations d'AcidIsland commencent par `acidisland.`. Chaque autorisation est listée dans la [Référence des autorisations](../../BentoBox/Permissions.md) avec `[gamemode]` à la place de `acidisland`. Pour les avantages VIP tels que des équipes plus grandes, des îles plus grandes et plus de maisons, consultez [Autorisations et Avantages VIP](../../BentoBox/Permissions-Guide.md).

## Commandes du joueur : qui les a par défaut { #player-commands-who-has-them-by-default }

Ces valeurs par défaut proviennent d'AcidIsland `addon.yml`. **Tout le monde** signifie que tous les joueurs ont l'autorisation à moins que vous la leur retiriez; **Opérateurs** signifie que vous devez la donner aux joueurs avec votre plugin d'autorisations. Exécutez `/bentobox perms` dans la console pour voir les valeurs par défaut de votre serveur.

| Autorisation | Commandes | Par défaut |
|---|---|---|
| `acidisland.island` | La commande du joueur elle-même | Tout le monde |
| `acidisland.island.create` | `create` | Tout le monde |
| `acidisland.island.home` | `go` | Tout le monde |
| `acidisland.island.homes` | `homes` | Tout le monde |
| `acidisland.island.sethome` | `sethome` | Tout le monde |
| `acidisland.island.deletehome` | `deletehome` | Tout le monde |
| `acidisland.island.renamehome` | `renamehome` | Tout le monde |
| `acidisland.island.spawn` | `spawn` | Tout le monde |
| `acidisland.island.info` | `info` | Tout le monde |
| `acidisland.island.near` | `near` | Tout le monde |
| `acidisland.island.reset` | `reset` | Tout le monde |
| `acidisland.island.name` | `setname`, `resetname` | Tout le monde |
| `acidisland.island.language` | `language` | Tout le monde |
| `acidisland.island.settings` | `settings` | Tout le monde |
| `acidisland.island.lock` | `lock` | Tout le monde |
| `acidisland.island.ban` | `ban`, `unban`, `banlist` | Tout le monde |
| `acidisland.island.expel` | `expel` | Tout le monde |
| `acidisland.island.team` | `team` | Tout le monde |
| `acidisland.island.team.invite` | `team invite` | Tout le monde |
| `acidisland.island.team.accept` | `team accept` | Tout le monde |
| `acidisland.island.team.reject` | `team reject` | Tout le monde |
| `acidisland.island.team.leave` | `team leave` | Tout le monde |
| `acidisland.island.team.kick` | `team kick` | Tout le monde |
| `acidisland.island.team.promote` | `team promote`, `team demote` | Tout le monde |
| `acidisland.island.team.setowner` | `team setowner` | Tout le monde |
| `acidisland.island.team.trust` | `team trust`, `team untrust` | Tout le monde |
| `acidisland.island.team.coop` | `team coop`, `team uncoop` | Tout le monde |

Les autorisations des administrateurs et modérateurs (`acidisland.admin.*`, `acidisland.mod.*`) sont pour les opérateurs par défaut. Voir [Autorisations du personnel](../../BentoBox/Permissions-Guide.md#staff-permissions).
