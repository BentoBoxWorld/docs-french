# Permissions SkyGrid

| Permission | Autoriser pour | Description |
| -----------| ----------- | ------- |
| skygrid.admin.clearresetall | op | Autoriser la suppression de la limite de réinitialisation d'aire de tous les joueurs |
| skygrid.admin.delete | op | Permettre à un joueur de supprimer complètement un joueur (régénère l'aire) |
| skygrid.admin.deleteisland | op | Permettre à un joueur de régénérer complètement l'aire sur laquelle se trouve le joueur |
| skygrid.admin.noban | op | Le joueur ne peut pas être banni d'une aire |
| skygrid.admin.register | op | Permettre à un joueur d'enregistrer l'aire la plus proche à un autre joueur |
| skygrid.admin.reload | op | Recharger le config.yml |
| skygrid.admin.reserve | op | Réserve un emplacement vide pour la prochaine aire d'un joueur |
| skygrid.admin.setlanguage | op | Réinitialise toutes les langues des joueurs et définit la langue par défaut |
| skygrid.admin.setspawn | op | Autoriser l'utilisation des outils de spawn |
| skygrid.admin.setrange | op | Autoriser la définition de la portée de protection d'aire |
| skygrid.admin.settingsreset | op | Réinitialiser toutes les aires aux paramètres de protection par défaut |
| skygrid.admin.unregister | op | Retirer un joueur d'une aire sans régénérer les blocs de l'aire |
| skygrid.mod.bypasscooldowns | op | Autoriser le modérateur à ignorer les délais d'attente |
| skygrid.mod.bypassdelays | op | Autoriser le modérateur à ignorer les délais |
| skygrid.mod.bypassexpel | op | Autoriser le modérateur à ignorer l'expulsion d'aire |
| skygrid.mod.bypasslock | op | Contourner un verrouillage d'aire |
| skygrid.mod.bypassprotect | op | Autoriser le modérateur à ignorer la protection d'aire |
| skygrid.mod.clearreset | false | Autoriser la suppression de la limite de réinitialisation d'aire |
| skygrid.mod.info | op | Permettre à un modérateur de voir les informations sur un joueur |
| skygrid.mod.lock | op | Verrouiller ou déverrouiller une aire |
| skygrid.mod.name | false | Autoriser la nomination des aires du joueur |
| skygrid.mod.resethome | op | Autoriser la définition ou la réinitialisation de la position d'accueil d'un joueur |
| skygrid.mod.resetname | false | Autoriser la réinitialisation des noms d'aire du joueur |
| skygrid.mod.team | false | Autoriser la modification des équipes via les commandes de coup de pied et d'ajout |
| skygrid.mod.tp | op | Autoriser la téléportation à une aire |
| skygrid.island.ban | true | Autoriser le bannissement des visiteurs |
| skygrid.island.expel | true | Autoriser l'expulsion des visiteurs |
| skygrid.island.home | true | Autoriser la téléportation à l'aire du joueur |
| skygrid.island.go | true | Utiliser la commande skygrid go |
| skygrid.island.language | true | Le joueur peut sélectionner une langue |
| skygrid.island.lock | false | Autoriser le verrouillage d'aire |
| skygrid.island.name | true | Le joueur peut définir le nom de son aire |
| skygrid.island.number | false | x définit le nombre d'aires que le joueur peut créer |
| skygrid.island.reset | true | Le joueur peut utiliser la commande de réinitialisation ou de redémarrage d'aire |
| skygrid.island.sethome | true | Permettre au joueur d'utiliser la commande sethome |
| skygrid.island.settings | true | Le joueur peut voir les paramètres |
| skygrid.island.spawn | true | Le joueur peut utiliser la commande de spawn d'aire si le spawn existe |
| skygrid.island.team | true | Permettre à un joueur d'utiliser les commandes d'équipe |
| skygrid.island.team.coop | true | Permettre à un joueur d'utiliser les commandes coop d'équipe |
| skygrid.island.team.trust | true | Permettre à un joueur d'utiliser les commandes d'équipe de confiance |
| skygrid.settings.* | true | Autoriser l'utilisation des paramètres sur l'aire |
| skygrid.island | true | Utiliser la commande <b>/skygrid</b> |
| skygrid.island.create | true | Autoriser la création d'une aire de joueur |
| skygrid.team.maxsize.[NUMBER] | false | Permettre à un joueur d'obtenir une taille d'équipe plus grande que la valeur par défaut |
| skygrid.island.maxhomes.[NUMBER] | false | Permettre à un joueur d'obtenir plus d'accueils que la valeur par défaut |
| skygrid.island.range.[NUMBER] | false | Permettre à un joueur d'obtenir une portée de protection plus grande que la valeur par défaut |
