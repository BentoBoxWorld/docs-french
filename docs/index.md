# BentoBox

BentoBox est un puissant plugin de bibliothèque Paper qui fournit des fonctionnalités essentielles pour les jeux de style île comme SkyBlock, AcidIsland, OneBlock et autres. Il offre des fonctionnalités telles que la création d'îles, la gestion d'équipes, la protection, etc. Ces jeux et fonctionnalités sont ajoutés à BentoBox via des addons qui fonctionnent comme des mini-plugins. Les administrateurs peuvent personnaliser leur serveur pour avoir exactement les jeux et fonctionnalités qu'ils souhaitent.
