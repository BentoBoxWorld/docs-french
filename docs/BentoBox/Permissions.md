# Permissions BentoBox

Les permissions listées ici sont pour BentoBox. Les compléments enregistrent leurs propres permissions.

**Permissions BentoBox (à partir de 1.6.0)**

| Permission             | Permission Parent | Valeur Par Défaut | Description                            |
|------------------------|-------------------|---------------|----------------------------------------|
| bentobox.admin         |                   | op            | Permet l'utilisation de la plupart des commandes BentoBox |
| bentobox.admin.catalog | bentobox.admin    | op            | Permet d'utiliser /bentobox catalog        |
| bentobox.admin.locale  | bentobox.admin    | op            | Permet d'utiliser /bentobox locale         |
| bentobox.admin.manage  | bentobox.admin    | op            | Permet d'utiliser /bentobox manage         |
| bentobox.admin.migrate | bentobox.admin    | op            | Permet d'utiliser /bentobox migrate        |
| bentobox.admin.reload  | bentobox.admin    | op            | Permet d'utiliser /bentobox reload         |
| bentobox.about         |                   | true          | Permet d'utiliser /bentobox about          |
| bentobox.version       |                   | true          | Permet d'utiliser /bentobox version        |
