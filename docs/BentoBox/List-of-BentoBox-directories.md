# database

C'est où la base de données à fichier plat est enregistrée (fichiers YAML). C'est où les données des compléments sont enregistrées.

BentoBox y conserve aussi ses propres tables, par exemple `Islands`, `Players`, `Names` et `WorldSettings`. La table `WorldSettings` contient un fichier par mode de jeu pour les paramètres de monde que BentoBox enregistre lui-même plutôt que dans le `config.yml` du mode de jeu, actuellement la liste des types d'entités toujours autorisés.
