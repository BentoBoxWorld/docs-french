# Qu'est-ce que les Drapeaux ?

Les drapeaux sont les paramètres d'île similaires aux [drapeaux de région de WorldGuard](https://worldguard.enginehub.org/en/latest/regions/flags/) : ils définissent si quelque chose est autorisé ou est susceptible de se produire à l'intérieur des limites de l'île.
