Les compléments sont ce qui rend BentoBox spécial. Ils fournissent les modes de jeu et les fonctions utilitaires pour eux.

Ceux-ci incluent certains Gamemodes populaires :
* [**BSkyBlock**](https://github.com/BentoBoxWorld/BSkyBlock) : Skyblock !
* [**AOneBlock**](https://github.com/BentoBoxWorld/AOneBlock) : vous avez un bloc !
* [**AcidIsland**](https://github.com/BentoBoxWorld/AcidIsland) : vous êtes échoué dans une mer d'acide !
* [**Boxed**](https://github.com/BentoBoxWorld/Boxed) : vous commencez dans une petite boîte 4x4 et ne pouvez l'agrandir qu'en complétant les Avancées !
* [**CaveBlock**](https://github.com/BentoBoxWorld/CaveBlock) : essayez de vivre sous terre !
* [**SkyGrid**](https://github.com/BentoBoxWorld/SkyGrid) : survivre dans un monde composé de blocs éparpillés - quelle aventure !

Et ceux-ci incluent certains Compléments officiels qui apportent des fonctionnalités incroyables, telles que :
* [**Level**](https://github.com/BentoBoxWorld/Level) : calculez votre niveau d'île et montrez un top dix.
* [**Challenges**](https://github.com/BentoBoxWorld/Challenges) : donne à vos joueurs des défis à accomplir.
* [**WarpSigns**](https://github.com/BentoBoxWorld/addon-welcomewarpsigns) : permet aux joueurs de planter un panneau warp et de visiter les îles d'autres joueurs.
* [**Biomes**](https://github.com/BentoBoxWorld/Biomes) : permet aux joueurs de changer les biomes sur les îles.
* [**invSwitcher**](https://github.com/BentoBoxWorld/addon-invSwitcher) : vous permet de diviser les inventaires entre les différents mondes du mode de jeu.
* [**VoidPortals**](https://github.com/BentoBoxWorld/VoidPortals) : se téléporte aux dimensions en tombant dans le Vide :
* [**MagicCobblestoneGenerator**](https://github.com/BentoBoxWorld/MagicCobblestoneGenerator) : génère n'importe quel bloc dans les générateurs de pierre de taille.
* [**IslandFly**](https://github.com/BentoBoxWorld/IslandFly) : permet à vos joueurs de voler sur leurs îles.
* [**Limits**](https://github.com/BentoBoxWorld/addon-limits) : limite les blocs et les entités que vos joueurs peuvent placer sur leurs îles.
* [**Greenhouses**](https://github.com/BentoBoxWorld/greenhouses) : permet aux joueurs de faire de petites maisons biome en verre sur leur île.

Et il y a beaucoup d'autres Compléments officiels ou créés par la communauté que vous pouvez essayer et utiliser pour votre serveur !

# Installer les Compléments

Premièrement, vous devez télécharger les Compléments que vous souhaitez ajouter à votre serveur. Les officiels peuvent être trouvés sur la [liste des dépôts BentoBoxWorld](https://github.com/BentoBoxWorld) (liens fournis ci-dessus) et peuvent être téléchargés à partir de leur onglet `Releases` (ou depuis [Jenkins](https://ci.codemc.io/job/BentoBoxWorld/) pour les **non testés** builds de développement).

Une fois que vous avez téléchargé tout ce dont vous avez besoin, il vous suffit de les mettre tous dans le dossier `plugins\BentoBox\addons`, de démarrer votre serveur pour que les fichiers de configuration et les dossiers se créent, et enfin de l'éteindre à nouveau pour pouvoir éditer tout ce dont vous avez besoin sans causer de dégâts à votre serveur.

Veuillez noter que les Compléments peuvent parfois être incompatibles avec la version de BentoBox que vous utilisez. Les Compléments Officiels seront **toujours** fournis avec une déclaration claire des versions qu'ils supportent. Cependant, notez qu'ils supportent souvent les versions plus récentes sans avoir besoin d'être mis à jour.
